 
<h1 align="center">  🔐 O Código da Segurança </h1>

Este projeto foi desenvolvido com o objetivo de **apresentar conceitos fundamentais de criptografia de forma prática e didática**, permitindo que o usuário **cripte e descripte mensagens** enquanto exercita o raciocínio lógico.

Além da funcionalidade principal, o projeto conta com **diversas atividades interativas**, criadas para ajudar no entendimento das cifras utilizadas e como utilizá-las na segurança de mensagens no dia a dia. Na seção **"Saiba mais"**, o usuário encontra explicações teóricas que complementam a prática, tornando o aprendizado mais completo.

O foco do projeto não é apenas o resultado final, mas **o processo de compreensão da lógica por trás da criptografia no nosso dia a dia**.


## 🚀 Tecnologias utilizadas

- **HTML** para estruturação das páginas  
- **CSS** para estilização e organização visual  
- **JavaScript** para lógica, interatividade e funcionamento das cifras  


## 💻 Funcionalidades

- Criptografia de mensagens
- Descriptografia de textos
- Atividades práticas para exercitar a lógica
- Conteúdo explicativo para aprofundar o entendimento das cifras
- Ferramentas auxiliares para apoiar o usuário durante o uso


## ▶️ Como utilizar

1. Insira o texto que deseja criptografar ou descriptografar
2. Escolha a atividade ou cifra desejada
3. Execute a ação e analise o resultado
4. Utilize a seção **"Saiba mais"** para entender o funcionamento de cada cifra aplicada


## 🧠 Aprendizados

Durante o desenvolvimento deste projeto, foram trabalhados conceitos como:
- Lógica de programação aplicada a problemas reais
- Manipulação de strings com JavaScript
- Organização de código e separação de responsabilidades
- Criação de interfaces focadas na experiência do usuário
- Resolução de problemas com base no raciocínio lógico

- Melhorias visuais no frontend
